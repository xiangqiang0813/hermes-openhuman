# Hermes OpenHuman 记忆增强恢复手册

## 前置条件检查

在进行任何恢复操作之前，请确保满足以下条件：

### 系统要求
- **Hermes Agent**：已安装并正常运行
- **Python环境**：版本 >= 3.8
- **Node.js**：版本 >= 16.0（用于飞书CLI）
- **磁盘空间**：至少 500MB 可用空间

### 备份文件准备
- **记忆备份**：`~/.hermes/memories/` 目录下的文件
- **配置备份**：`~/.hermes/config/` 目录下的配置文件
- **脚本备份**：`~/.hermes/scripts/update_memory.py`

## 恢复配置步骤

### 第一步：基础配置恢复

```bash
# 进入Hermes目录
cd ~/.hermes

# 检查并创建必要的目录结构
mkdir -p memories archive/daily scripts config

# 恢复记忆文件
cp /path/to/backup/MEMORY.md memories/
```

### 第二步：安装依赖包

```bash
# 安装Python依赖
pip install json datetime subprocess hashlib

# 安装飞书CLI
npm install -g @larksuite/cli

# 验证安装
lark-cli --version
```

### 第三步：飞书授权配置

```bash
# 初始化飞书CLI配置
lark-cli config init --new

# 绑定到Hermes
lark-cli config bind

# 用户授权登录
lark-cli auth login --recommend

# 扩展文档搜索权限
lark-cli auth login --scope "search:docs:read"
```

### 第四步：验证授权状态

```bash
# 检查当前授权状态
lark-cli auth status

# 预期输出：显示有效的访问令牌和权限列表
```

## 记忆系统恢复

### 指纹系统恢复

```bash
# 创建指纹文件
touch ~/.hermes/archive/.fingerprint

# 初始化空指纹数据
echo '{}' > ~/.hermes/archive/.fingerprint
```

### cronjob调度恢复

```bash
# 编辑crontab
crontab -e

# 添加每小时执行的任务
0 * * * * cd ~/.hermes && python3 scripts/update_memory.py >> logs/memory.log 2>&1
```

### 归档目录恢复

```bash
# 创建归档目录
mkdir -p ~/.hermes/archive/daily

# 设置正确的权限
chmod 755 ~/.hermes/archive/daily
```

## 常见问题处理

### 问题1：飞书CLI认证失败

**症状**：`lark-cli auth login` 返回认证错误
**解决方案**：
```bash
# 清除现有认证
lark-cli auth logout

# 重新登录
lark-cli auth login --recommend
```

### 问题2：记忆更新脚本执行失败

**症状**：cronjob运行但无效果
**解决方案**：
```bash
# 手动执行脚本查看详细错误
python3 update_memory.py

# 检查日志文件
tail -n 20 logs/memory.log
```

### 问题3：Token计算异常

**症状**：记忆文件过大或过小
**解决方案**：
```bash
# 重置记忆文件
echo "# 记忆概览\n\n📅 日程: 无\n📋 任务: 无\n📄 文档: 无\n\n(last updated: $(date '+%Y-%m-%d %H:%M:%S'))" > memories/MEMORY.md

# 重新执行更新
python3 scripts/update_memory.py
```

## 监控与维护

### 定期健康检查

```bash

ls -la ~/.hermes/archive/daily/

# 每周检查记忆文件大小
du -sh ~/.hermes/memories/

# 每月检查授权状态

```

### 故障预警设置

建议配置以下监控项：
- **cronjob失败报警**：邮件通知脚本执行异常
- **磁盘空间警告**：当归档目录超过80%容量时提醒
- **API调用失败统计**：记录飞书API调用成功率
- **记忆更新间隔监控**：确保每小时正常执行

## 紧急恢复方案

如果系统完全无法正常工作，可以执行以下紧急恢复：

```bash
# 1. 停止所有相关进程
pkill -f "update_memory.py"

# 2. 备份当前状态
cp -r ~/.hermes ~/hermes-backup-$(date +%Y%m%d)

# 3. 重置到干净状态
rm -rf ~/.hermes/*
mkdir -p ~/.hermes/{memories,archive/daily,scripts,config}

# 4. 重新安装基础配置
lark-cli config init --new
lark-cli auth login --recommend

# 5. 重新部署记忆更新脚本
cp /path/to/backup/update_memory.py ~/.hermes/scripts/
chmod +x ~/.hermes/scripts/update_memory.py

# 6. 重新设置cronjob
crontab -e
# 添加：0 * * * * cd ~/.hermes && python3 scripts/update_memory.py
```
